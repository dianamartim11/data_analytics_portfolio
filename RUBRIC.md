# ✅ Marking Rubric

Total: **100 points.** This pairs with `SKILLS_CHECKLIST.md` (which lists every
skill and the evidence to capture). If every checklist box is ticked, you'll score
well here.

| Stage | Area | Points |
|---|---|---|
| 1 | Excel | 15 |
| 2 | SQL | 20 |
| 3 | Python (cleaning + EDA + notebook) | 20 |
| 4 | Statistics & modelling | 20 |
| 5 | Power BI | 15 |
| 6 | Report, storytelling & professionalism | 10 |

---

## 1. Excel — 15
- [ ] Imported data, cleaned with `TRIM`/`PROPER`/Find&Replace (3)
- [ ] `IF`/`SUMIF`/`COUNTIF`/`AVERAGEIF` used (3)
- [ ] `VLOOKUP`/`XLOOKUP` or `INDEX/MATCH` to join products onto orders (3)
- [ ] Remove duplicates + conditional formatting + data validation (3)
- [ ] PivotTables + PivotChart + a one-page dashboard (3)

## 2. SQL — 20
- [ ] Tables created and clean data loaded (2)
- [ ] Basics: SELECT/WHERE/ORDER BY/LIMIT (2)
- [ ] GROUP BY + HAVING + aggregates (3)
- [ ] INNER and LEFT joins across tables (4)
- [ ] CASE, date grouping, subquery (3)
- [ ] CTE (`WITH`) (2)
- [ ] Window function (RANK / running total / LAG) (4)

## 3. Python — 20
- [ ] All 5 tables cleaned to `data/processed/` (dates, prices, phones, dupes, missing) (6)
- [ ] Tables merged; `revenue` and `profit` derived (3)
- [ ] `groupby`/`pivot_table` answers the questions (3)
- [ ] 4+ saved charts (bar, line, histogram, box/heatmap) (4)
- [ ] A Jupyter notebook that narrates the analysis (4)

## 4. Statistics & modelling — 20
- [ ] Descriptive stats + IQR outlier detection (3)
- [ ] Confidence interval computed (2)
- [ ] A/B test with a significance test + correct conclusion (4)
- [ ] Linear regression, interpreted (3)
- [ ] Logistic regression, interpreted (3)
- [ ] Time series: moving average + growth % + seasonality comment (3)
- [ ] RFM customer segmentation (2)

## 5. Power BI — 15
- [ ] Data imported with correct types (2)
- [ ] A Power Query transform step (2)
- [ ] Table relationships modelled (3)
- [ ] At least 3 DAX measures (incl. a profit margin %) (4)
- [ ] 4+ visuals, KPI cards, 2+ slicers on one page (2)
- [ ] `.pbix` saved + dashboard screenshot exported (2)

## 6. Report & professionalism — 10
- [ ] `reports/findings.md` answers all 7 business questions with embedded charts (3)
- [ ] 3 actionable recommendations (2)
- [ ] **Data ethics / PII note** (2)
- [ ] Polished top-level `README.md` portfolio page (2)
- [ ] Clean, frequent git commits (1)
